# Quest artwork

Approved sunset mech concept: `mech-sunset-source.png`, generated with the built-in image tool from `img/mechrewired-visual-target.png` as a mood reference.

The SVG files provide editable Meta layouts referencing the source PNG. Render them from this directory so the relative image reference resolves. App icons are resized from the source.
