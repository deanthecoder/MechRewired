# MetalPlates013

The MetalPlates013 color, metalness, OpenGL normal and roughness maps are from
[ambientCG](https://ambientcg.com/a/MetalPlates013), released under the
[Creative Commons CC0 1.0 Universal license](https://creativecommons.org/publicdomain/zero/1.0/).

They provide the lower cockpit-side armor's plate seams, fasteners and restrained rust. Displacement
and DirectX-normal maps are omitted because this treatment does not need geometric deformation.
