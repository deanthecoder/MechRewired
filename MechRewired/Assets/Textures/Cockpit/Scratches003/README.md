# Scratches003

`Scratches003_1K-PNG_Color.png` and `Scratches003_1K-PNG_NormalGL.png` are from the Scratches003
surface-imperfection texture set from
[ambientCG](https://ambientcg.com/a/Scratches003), released under the
[Creative Commons CC0 1.0 Universal license](https://creativecommons.org/publicdomain/zero/1.0/).

The cockpit-glass shader uses the color map as a sparse scratch mask and the OpenGL normal map
to make those marks catch moving highlights. The asset's other PBR maps are unnecessary for the
intentionally subtle treatment.
