# Terrain textures

The terrain detail materials are [Ground054](https://ambientcg.com/view?id=Ground054) and
[Ground088](https://ambientcg.com/view?id=Ground088) from ambientCG. Both are provided under
the [CC0 1.0 licence](https://creativecommons.org/publicdomain/zero/1.0/).

Only the 1K colour, OpenGL normal and roughness maps are retained. MechRewired uses them as
world-space detail over the original MW2 palette colours; it does not use their displacement maps.
